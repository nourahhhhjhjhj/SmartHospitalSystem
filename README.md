# Smart Hospital Management System

نظام إدارة مستشفى مبني بـ ASP.NET Core MVC (.NET 8) و SQL Server.

## المميزات
- تسجيل دخول وأدوار (Admin, Doctor, Receptionist)
- لوحة تحكم بإحصائيات المرضى والأطباء والمواعيد
- إدارة المرضى (إضافة، تعديل، بحث، حذف)
- إدارة الأطباء والأقسام
- واجهة عربية RTL

## التقنيات
ASP.NET Core MVC, Entity Framework Core, SQL Server, Bootstrap 5
